# ポモドーロタイマー 機能一覧

## 概要

このドキュメントでは、ポモドーロタイマーアプリケーションで実装が必要な機能を一覧化しています。

---

## 🔧 バックエンド（Flask）

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **Flaskアプリ起動** | `create_app` ファクトリパターンでの初期化 | 必須 |
| **メインページ表示** | `GET /` でindex.htmlを返す | 必須 |
| **設定API（取得）** | `GET /api/settings` タイマー設定の取得 | オプション |
| **設定API（保存）** | `POST /api/settings` タイマー設定の保存 | オプション |
| **TimerService** | モード別の時間計算、長休憩判定ロジック | 必須 |
| **環境別設定** | Config / TestConfig / ProductionConfig | 必須 |

---

## 🎨 フロントエンド（UI）

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **円形プログレスタイマー** | 残り時間を円形で視覚的に表示 | 必須 |
| **時間表示** | `MM:SS` 形式で残り時間を表示（例: 25:00） | 必須 |
| **モード表示** | 「作業中」「休憩中」などの状態表示 | 必須 |
| **開始ボタン** | タイマーをスタート/一時停止 | 必須 |
| **リセットボタン** | タイマーを初期状態に戻す | 必須 |
| **今日の進捗表示** | 完了したポモドーロ数を表示 | 必須 |
| **集中時間表示** | 合計の集中時間を表示（例: 1時間40分） | 必須 |

---

## ⏱️ タイマーロジック（JavaScript）

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **カウントダウン** | 1秒ごとに残り時間を減らす | 必須 |
| **時間フォーマット** | 秒数を `MM:SS` 形式に変換 | 必須 |
| **進捗計算** | プログレスバーの進捗率を計算 | 必須 |
| **モード切り替え** | ポモドーロ → 短い休憩 → ポモドーロ → ... → 長い休憩 | 必須 |
| **タイマー完了検知** | 0になったら次のモードへ遷移 | 必須 |
| **状態管理** | `timerState` オブジェクトで状態を一元管理 | 必須 |

---

## ⚙️ 設定機能

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **ポモドーロ時間設定** | デフォルト25分 | 必須 |
| **短い休憩時間設定** | デフォルト5分 | 必須 |
| **長い休憩時間設定** | デフォルト15分 | 必須 |
| **localStorage保存** | 設定・進捗のブラウザ永続化 | オプション |

---

## 🔔 追加機能（Phase 5）

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **通知** | タイマー完了時のブラウザ通知 | オプション |
| **サウンド** | 完了時のアラーム音 | オプション |
| **アニメーション** | プログレスバーのスムーズな動き | オプション |

---

## 🧪 テスト

| 機能 | 説明 | 優先度 |
|------|------|--------|
| **Python単体テスト** | TimerService、ルートのテスト | 必須 |
| **JavaScriptテスト** | timerEngine の純粋関数テスト | 必須 |
| **E2Eテスト** | 統合テスト（Playwright） | オプション |

---
